# The Glassbox Manifesto

## Agents are not stupid. They are blind.

A capable agent asked to work on a system it has never seen will produce paths,
ports, statuses, and response shapes — confidently. Some of them will even be
right. That is the problem: confidence without perception is indistinguishable
from accuracy, right up until it isn't.

Professional engineers have a word for this feeling: *someone else's system*.
The API with no documentation. The legacy process nobody remembers writing. The
protocol that must be decoded from captures. The flow that has fifteen steps
and two of them bite. This is not the exception in real work. This is the work.

## Method is a gift you can package.

We spent years learning, the hard way, how to move through systems we did not
build: what to trust, what to write down, what to prove, when to stop. Every
lesson came with a scar — a confident guess that cost a day, a retry storm that
cost an account, a test that passed because it tested nothing.

Those lessons compress. They fit in skills. They can be handed to an agent like
a field manual, and the agent stops guessing.

## What we believe

- **The wire is the truth.** Observed behavior outranks any document, any SDK,
  and any memory — including the agent's own.
- **A model is a thing you write down.** If it lives only in a context window,
  it dies at the next compaction. Files outlive sessions.
- **No claim without an artifact.** "Should work" is the most expensive phrase
  in engineering. Commands and outputs are cheap.
- **Failure is a first-class outcome.** A precise "blocked" beats a vague
  "kept trying", every single time.
- **Boundaries are part of the method.** Authorized scope, human gates,
  honest classification of protection surfaces, stopping when a system
  defends itself. Power with a boundary is engineering. Power without one is
  something else.
- **Small, sharp skills beat giant ones.** Twelve manuals you can actually
  load beat a book nobody reads.

## What this is

A skill pack: vendor-neutral, tool-agnostic, zero-dependency manuals that any
coding agent — Claude Code, Codex, Cursor, opencode, Gemini CLI, Copilot,
Windsurf, whatever comes next — can load and follow. Perception, protocol
cartography, flow modeling, evidence discipline, durable autonomy, adversarial
review. The full loop, not a vibe.

Install it with one command. Watch your agent stop guessing.

## What this is not

Not a hacking kit. Not an extraction toolkit. Not a collection of clever ways
around other people's protections. The skills deliberately teach the *respectful*
path — classify, respect, gate, disclose — because that is the only way this
work scales without turning into something we would not want our names on.

The boundary is not a constraint on the method. The boundary *is* the method.

## The invitation

Use the skills. Break them. Rebuild them for your domain. Send back the field
notes. The systems will keep getting stranger; the method is how we keep up.

**Turn black boxes into glass boxes.**
